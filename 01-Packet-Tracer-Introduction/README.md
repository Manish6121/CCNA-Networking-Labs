# Lab 01: Packet Tracer Introduction

## Overview
This is my first hands-on CCNA networking lab, created using Cisco Packet Tracer.

## Tools Used
- Cisco Packet Tracer
- Cisco 2960-24TT Switch
- 2 End Devices (PCs)

## Network Topology
Two PCs are connected to a single Layer 2 switch using Ethernet connections.

## IP Addressing

| Device | IP Address | Subnet Mask |
|---|---|---|
| PC0 | 192.168.1.1 | 255.255.255.0 |
| PC1 | 192.168.1.2 | 255.255.255.0 |

## Practical Tasks
- Created a basic LAN topology.
- Connected two PCs to a Cisco switch.
- Configured static IPv4 addresses.
- Verified switch port connectivity.
- Tested communication using the ping command.

## Verification

Command used:

`ping 192.168.1.2`

The objective was to verify communication between both PCs on the same network.

## Key Learnings
- Basic Packet Tracer navigation.
- Connecting end devices to a switch.
- Static IPv4 addressing.
- Basic LAN communication.
- Using ping to test connectivity.
